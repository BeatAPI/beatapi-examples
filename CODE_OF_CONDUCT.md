# Code of Conduct

## Our standard

BeatAPI welcomes developers of every background and experience level. Be
respectful, assume good intent, give actionable technical feedback, and keep
discussions focused on improving developer integrations.

Unacceptable behavior includes harassment, discrimination, threats, publishing
private information, sharing credentials or customer data, and repeatedly
disrupting project discussions.

## Scope

This standard applies to repository issues, pull requests, discussions, and
other spaces where someone is representing the BeatAPI project.

## Reporting

Report conduct concerns privately to support@beatapi.io. Do not use a public
issue when a report contains personal information, credentials, security
details, or customer data.

Project maintainers may edit or remove contributions and may temporarily or
permanently restrict participation when behavior is unsafe or disruptive.
